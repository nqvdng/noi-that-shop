# Website nội thất (bản mẫu)

Trang tĩnh một file: `index.html` (HTML, CSS, JS thuần, không cần build).

## Xem thử
Mở `index.html` bằng trình duyệt, hoặc bật GitHub Pages (Settings > Pages > Deploy from branch > main).

## Nguồn thông tin
- Thông tin công ty, địa chỉ, liên hệ, công trình: hồ sơ năng lực PKK Group 2026.
- Giá, kích thước, mô tả sản phẩm, tên "Mộc Nhà": nội dung giả định, cần thay bằng số liệu thật.

## Việc cần làm tiếp
- Thay hình minh họa bằng ảnh sản phẩm và ảnh công trình thật.
- Bổ sung dự án nội thất đã hoàn thiện.
- Kiểm tra số Zalo, email liên hệ.
- Thông báo website bán hàng với Bộ Công Thương nếu bán hàng trực tuyến.
